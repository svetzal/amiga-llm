# Experiments

Experiments turn uncertainty into recorded evidence. Each file has a
falsifiable hypothesis, the smallest procedure that can refute it, fixed
inputs and environment details, measurements with their evidence tier, a
conclusion, and the decision that follows.

The number, gloss and status of each experiment live in its front matter (see
`AGENTS.md`). This directory listing is the index. A generated index will
replace it once there are enough experiments to need one.

Do not rewrite a hypothesis after observing the result. Append.
